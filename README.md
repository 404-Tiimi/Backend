# Haaga-Helia survey service (Course Ohjelmistoprojekti 1)
This project is an collaboration project in a course Ohjelmistoprojekti 1 where participants create functioning application that has possible real life use case.

Questionnaire is a survey service where users can anonymously answer to presented surveys via shared link. In the current state the survey creation supports open and multiple choice questions.
