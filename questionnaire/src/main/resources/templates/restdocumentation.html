Overview

  • All endpoints live under the base path /rest.
  • Requests and responses use JSON (Content-Type: application/json).
  • No login is required and CSRF protection is disabled for /rest/**.
  • CORS is allowed from http://localhost:5173 and https://404-Tiimi.github.io for GET, POST and OPTIONS.

Typical answering flow

  1. Fetch the inquiry and its questions: GET /rest/inquiry/{id}
  2. Start an answering session: POST /rest/sessions
  3. Submit all answers with the returned session id: POST /rest/answers
Method Path Description
GET /rest/inquiries List all inquiries with their questions
GET /rest/inquiry/{id} Get one inquiry by id
POST /rest/sessions Start a new answering session
GET /rest/answers List all saved answers
POST /rest/answers Save a batch of answers to a session
GET /rest/inquiries

Returns every inquiry in the database, including its questions.

Responses

  • 200 OK – array of inquiries (empty array if there are none).

Example response

[
  {
    "id": 1,
    "title": "Customer feedback",
    "description": "Tell us what you think",
    "author": { "id": 1, "role": "ADMIN", "username": "admin" },
    "createDate": "2026-11-20",
    "deadlineDate": "2026-12-31",
    "questions": [
      { "id": 2, "quest": "What did you like?", "type": "TEXT", "options": [] },
      { "id": 3, "quest": "Would you recommend us?", "type": "RADIO", "options": ["Yes", "No", "Maybe"] }
    ]
  }
]
GET /rest/inquiry/{id}

Returns a single inquiry and its questions.

Path parameters

NameTypeDescription
idintegerId of the inquiry

Responses

  • 200 OK – the inquiry object.
  • 200 OK with body null – no inquiry exists with that id.

Example response

{
  "id": 1,
  "title": "Customer feedback",
  "description": "Tell us what you think",
  "author": { "id": 1, "role": "ADMIN", "username": "admin" },
  "createDate": "2026-11-20",
  "deadlineDate": "2026-12-31",
  "questions": [
    { "id": 2, "quest": "What did you like?", "type": "TEXT", "options": [] },
    { "id": 3, "quest": "Would you recommend us?", "type": "RADIO", "options": ["Yes", "No", "Maybe"] }
  ]
}
POST /rest/sessions

Creates a new answering session with startedAt set to the current server time. Use the returned id as sessionId when saving answers.

Request body

None.

Responses

  • 200 OK – the created session.

Example response

{
  "id": 7,
  "startedAt": "2026-11-26T14:32:05.123456",
  "completedAt": null
}
GET /rest/answers

Returns every saved answer, each with its question and session.

Responses

  • 200 OK – array of answers (empty array if there are none).

Example response

[
  {
    "id": 10,
    "question": { "id": 3, "quest": "Would you recommend us?", "type": "RADIO", "options": ["Yes", "No", "Maybe"] },
    "session": { "id": 7, "startedAt": "2026-11-26T14:32:05.123456", "completedAt": null },
    "answer": "Yes"
  }
]
POST /rest/answers

Saves all answers in the request to an existing session. If the session or any question is not found, nothing is saved.

Request body

FieldTypeDescription
sessionIdintegerId returned by POST /rest/sessions
answersarrayList of answer objects
answers[].questionIdintegerId of the question being answered
answers[].textstringFree text, or the chosen option for a RADIO question

Example request

{
  "sessionId": 7,
  "answers": [
    { "questionId": 2, "text": "Fast delivery" },
    { "questionId": 3, "text": "Yes" }
  ]
}

Responses

  • 200 OK – array of the saved answers (same shape as GET /rest/answers).
  • 404 Not Found – "Session not found" or "Question not found".
